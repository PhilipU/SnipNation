# Code of conduct

Treat other contributors with respect. Keep feedback specific to the work, make room for different experience levels, and respect personal boundaries. Harassment, discrimination, threats, and sharing private information without consent are unacceptable.

Use [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) to report conduct concerns privately to GitHub Support or to the repository maintainer when that option is available.

The maintainer may remove harmful content or restrict participation to protect contributors.
